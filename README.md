# ลอยกระทงออนไลน์ ๒๕๖๙ (Local Custom Loy Krathong Web App)

เว็บแอปพลิเคชันจำลองประเพณีลอยกระทงคืนวันเพ็ญแบบ Local 100% ที่ถอดแบบประสบการณ์มาจาก `season.sanook.com/loykrathong/` พร้อมฟีเจอร์ปรับแต่งและอัปโหลดรูปภาพได้เองทุกส่วน

---

## ✨ ฟีเจอร์เด่น (Key Features)

1. **ฉากแม่น้ำคืนวันเพ็ญแบบไดนามิก (Multi-layer River Scene):**
   - ทิวทัศน์ริมแม่น้ำเจ้าพระยา พระจันทร์เต็มดวงสว่างนวล พระปรางค์วัดอรุณราชวราราม
   - โคมลอย (Sky Lanterns) ลอยพัดพลิ้วตามแรงลมขึ้นสู่ท้องฟ้า
   - พลุไฟและสะเก็ดประกายไฟระเบิดเรืองแสงเป็นระยะ
   - สายน้ำไหลเอื่อยพร้อมคลื่นสะท้อนแสงจันทร์ และเงาสะท้อนของกระทงที่ลอยน้ำตามจริง
   - กระทงลอยแบบ Perspective Depth 3 ระดับ (ไกล, กลาง, ใกล้) พร้อมป้ายชื่อผู้ลอย
   - คลิกที่กระทงใบใดก็ได้เพื่อเปิด **Speech Bubble** อ่านคำอธิษฐาน และบันทึกภาพการ์ดได้ทันที

2. **สตูดิโอแต่งกระทง 3 ขั้นตอน (`/play` Wizard):**
   - **ขั้นตอนที่ 1: เลือกฐานกระทง**
     - ฐานกระทงโบราณและขนมไทยมงคล 6 แบบ (กระทงใบตองดั้งเดิม, ขนมดาราทอง/ทองเอกกระจัง, ขนมโคักษาสวรรค์, ข้าวจี่ชุบไข่, ข้าวแต๋นน้ำแตงโม, ขนมชั้นมงคล ๙ ชั้น)
     - ปุ่ม **"+ อัปโหลดฐานใหม่"** อัปโหลดภาพของตัวเองเพิ่มเข้าคลังได้ถาวร
   - **ขั้นตอนที่ 2: ตกแต่งกระทง & อัปโหลดรูปภาพ**
     - ดอกไม้มงคล 5 ชนิดพร้อมความหมาย (ดาวเรือง, บานไม่รู้โรย, กล้วยไม้, ดอกรัก, ดอกเข็ม)
     - ธูปเทียนเรืองแสง, เหรียญนำโชค, กลีบบัวหลวง
     - ปุ่ม **"+ อัปโหลดรูปภาพเอง"** นำรูปถ่าย สติกเกอร์ หรือโลโก้มาวางบนกระทงได้อิสระ
     - เครื่องมือจัดการชิ้นส่วน: คลิกลากย้ายตำแหน่ง, ย่อ-ขยาย, หมุนองศา, สลับเลเยอร์หน้า-หลัง, และลบชิ้นส่วน
   - **ขั้นตอนที่ 3: อธิษฐาน & ลอยกระทง**
     - เติมคำอธิษฐานอัตโนมัติตามดอกไม้ที่เลือก หรือคลิกแท็กคำอธิษฐานสำเร็จรูป
     - เมื่อกด "ลอยกระทงกันเลย!" จะมีเอฟเฟกต์พลุเฉลิมฉลอง เสียงประทัด/ระฆัง และปล่อยกระทงลงสู่แม่น้ำทันที

3. **ระบบเปลี่ยนและปรับแต่งฉากหลัง (Custom Background Settings):**
   - อัปโหลดภาพวิวหรือรูปถ่ายฉากหลังของตัวเอง (JPG, PNG, WebP, GIF)
   - สไลเดอร์ปรับความสูงระดับผิวน้ำ (Waterline Height 30% - 85%) ให้เข้ากับภาพฉากหลัง
   - สไลเดอร์ปรับความชัดของเงาสะท้อนกระทงบนผิวน้ำ (Reflection Opacity 0% - 100%)

4. **หน้ารวมคำอธิษฐาน & ดาวน์โหลดการ์ดที่ระลึก (`/blessing` Feed):**
   - ค้นหาคำอธิษฐานตามชื่อหรือข้อความ
   - บันทึกการ์ดอวยพรวันลอยกระทงความละเอียดสูง (PNG Card) กรอบลายไทยสีทองพร้อมแชร์ลงโซเชียลมีเดีย

5. **ระบบจัดเก็บข้อมูลภายในเครื่อง (Local Persistence & Backup):**
   - ใช้ **IndexedDB** บันทึกรูปภาพและกระทงทั้งหมดไว้ในเบราว์เซอร์ ไม่ติดลิมิตขนาดไฟล์
   - ฟังก์ชัน **Export / Import JSON** สำรองข้อมูลทั้งหมดไว้ใช้งานข้ามเครื่องได้

6. **ระบบเสียงสังเคราะห์ (Web Audio API):**
   - เสียงระฆังไทย (Thai Chime)
   - เสียงคลื่นน้ำและกระทงลงน้ำ (Water Splash)
   - เสียงพลุระเบิดบนฟ้า (Firework Boom)
   - สามารถเปิด/ปิดเสียงได้ตลอดเวลา

## 🚀 วิธีการเปิดใช้งาน (How to Run)

เนื่องจากเป็น Vanilla HTML5/CSS3/JavaScript แบบ Local-First คุณสามารถเปิดใช้งานได้ 2 วิธี:

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์ `index.html`
เปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์สมัยใหม่ (Google Chrome, Microsoft Edge, Firefox, Safari) ได้ทันที

### วิธีที่ 2: รันผ่าน Local Web Server เบาๆ
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์:

```bash
# ใช้ Python
python -m http.server 3000

# หรือใช้ Node.js npx
npx serve .
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
